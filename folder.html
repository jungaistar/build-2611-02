폴더 분류·추출

폴더를 통째로 올리면 안의 엑셀·PDF 를 규칙(파일 이름·머리글·본문 낱말)으로 문서 종류별로 나눕니다. 종류마다 정한 항목을 뽑고, 추출 조건에 맞는 행만 남겨 엑셀로 저장합니다. 같은 규칙 파일로 Codex 가 로컬 스크립트를 돌려 폴더를 주기적으로 처리할 수 있습니다.

1. 폴더를 올리세요

하위 폴더까지 모두 읽습니다. 엑셀(.xlsx·.xls)·CSV·PDF(글자가 든 것)만 분류하고, 다른 파일은 「건너뜀」으로 보여 줍니다.

예제 폴더는 견적서·거래명세서·검사성적서 각 2개, 확인 필요 1개, 미분류 1개, 메모 파일 1개입니다(가짜 업체). 예제 데이터는 실제 사내 데이터가 아닙니다.

2. 분류 결과

점수는 규칙 파일의 낱말이 파일 이름·머리글·본문에 있을 때마다 그 가중치를 더한 값입니다. 근거를 보고 틀리면 종류를 고르세요. 최소 점수에 못 미치면 「미분류」, 1·2위 점수 차이가 기준 이내면 「확인 필요」입니다. 둘 다 사람이 고르기 전에는 뽑지 않습니다.

3. 종류별 추출 결과

칸의 작은 표시는 값이 어디서 왔는지입니다 — 표시가 없는 값은 문서에 적힌 그대로입니다. 추출 조건에 맞지 않은 행은 사유와 함께 「뺀 행」에 남깁니다.

4. 분류 규칙

문서 종류마다 판정 낱말(가중치)·최소 점수·뽑을 항목·추출 조건을 정합니다. 아래 JSON 을 고치고 「적용」을 누르면 다시 분류합니다. 규칙은 이 브라우저에 저장됩니다. 내려받은 파일을 리포의 rules/doc-types.json 에 덮어쓰면 로컬 스크립트도 같은 규칙으로 돕니다.

5. Codex 로 폴더를 주기적으로 처리하기

Codex 는 웹페이지 안에서 돌지 않습니다. 대신 리포의 AGENTS.md(Codex 작업 지시서)와 로컬 스크립트를 씁니다. 스크립트는 이 화면과 같은 엔진·같은 규칙 파일로 분류하고 결과 엑셀을 만듭니다.

node tools/folder-run.mjs <폴더> --rules rules/doc-types.json --out 결과.xlsx --processed processed.json

--processed 를 주면 이미 처리한 파일(경로·크기·고친 시각이 같은 것)은 건너뜁니다. npm 설치가 필요 없습니다(node 만 있으면 됩니다). 자세한 절차는 사용법 — 폴더 분류에 있습니다.
