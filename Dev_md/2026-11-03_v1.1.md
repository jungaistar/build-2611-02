# 2026-11-03 v1.1 — 폴더 단위 자동 분류·추출

추가 요청: 패들릿 게시물 4128450933 「추가개선 방안」(원문은 CLAUDE.md 부록 B).
수강생에게 패들릿 댓글로 약속한 범위 그대로 만들었다 — 웹에 「폴더 통째로 올리기」, 규칙(파일 이름·머리글·들어 있는 낱말)으로 문서 종류 분류, 종류마다 조건에 맞는 데이터 추출, 웹에 분류해 보여 주기, 엑셀 저장. Codex 는 웹 안에서 돌지 않으므로 작업 지시서(AGENTS.md)와 같은 규칙을 쓰는 로컬 스크립트를 함께 준다.

## 한 일
- 판정 모듈 `js/classify.js`(UMD, `engine.js` 위에): 규칙 검사(`checkRules` — 고칠 곳을 모두 알려 줌), 문서 모으기(`docOf` — 파일 이름·머리글 낱말·본문 낱말), 종류 점수와 근거(`scoreType`·`classify` — 미분류·확인 필요), 뽑을 항목 짝짓기(`mapFields` — v1.0 `scorePair` + 규칙 파일 `aliases`), 추출 조건(`checkRow` — `>=` `<=` `>` `<` `=` `!=` `between` `contains` `notContains` `notEmpty`), 문서·폴더 추출(`extractDoc`·`runFolder` — 사람이 고른 종류 우선), 엑셀(`exportBook` — 분류표 + 종류별 시트 + 뺀 행 + 확인할것 + 건너뛴 파일), 이미 처리한 파일 기록, 예제 폴더 정의(`sampleFolder`·`samplePdf`).
- 규칙 파일 `rules/doc-types.json` — 예제 종류 3가지(견적서·거래명세서·검사성적서, 가짜). 엔진의 `DEFAULT_RULES` 와 같아야 한다(테스트).
- 화면 `folder.html` · `js/folder.js`: 폴더 고르기(`webkitdirectory`)·끌어다 놓기(하위 폴더까지 펼침)·파일 여러 개, 종류별 묶음 → 파일(경로·점수·근거·종류 고르기) → 종류별 추출 행(값 출처 표시) → 조건에 맞은 행/뺀 행, 엑셀, 규칙 요약·JSON 고치기·내려받기·올리기·기본값(localStorage), Codex 안내. 상단 메뉴(index·guide)에 「폴더 분류」, 첫 화면 파일 카드에 「예제 폴더로 바로 보기」(folder.html#example).
- 로컬 스크립트 `tools/folder-run.mjs`(+ `tools/read-node.mjs`): npm 의존성 없이 `lib/` 의 SheetJS·pdf.js 와 같은 엔진·같은 규칙 파일. `--rules` `--out` `--processed` `--json`. 결과 파일을 읽는 폴더 안에 쓰지 않는다. 틀린 규칙이면 종료 코드 2.
- 예제 폴더 `samples/`(9개: xlsx 7 · pdf 1 · 메모 txt 1) — `tools/make-samples.mjs` 로 만든다.
- `AGENTS.md`(Codex 작업 지시서): 목적·폴더 구조·규칙 고치는 법·실행·결과 확인·하지 않을 것·요청 예시 3개.
- guide.html 「6. 폴더 분류·추출(v1.1)」 절(규칙 칸 표·Codex 사용), README·CLAUDE.md 갱신, 기획서 v1.1.
